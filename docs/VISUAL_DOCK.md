# 后视 AprilTag 对准候选

本候选沿第九分支开发，使用 tag36h11 和独立于地图定位的短步倒车。停靠局部坐标中标签中心为 (-0.4, 0) m，目标轮轴为 (0, 0)，车头朝 +X；相机居中、位于轮轴后 0.20 m、朝后。完成条件是停稳后的新鲜观测满足相机到标签 0.20±0.02 m、轮轴横向偏差不超过 0.02 m、朝向误差不超过 3°。状态称为“视觉对准完成”，不表示充电。

用户更正黑色标记方框边长为 8 cm，相机中心离地为 14 cm；相机水平且居中正对车尾。静态预览已识别 tag36h11 ID 1；尺寸、安装角度和测距仍需现场核验。纸张白边不计入标记边长。

RK 相机使用独立线程请求 MJPEG 640×480，直接加载同包内已复核的 `mf200_640x480.yaml`，需要 Python 的 NumPy、PyYAML 与支持 `DICT_APRILTAG_36h11` 的 OpenCV aruco。本轮只读预览已核对设备、依赖及 MJPEG 640×480；标定几何仍需现场验收。PC 通过现有 SSH 连接的独立通道取 JPEG；预览可能延迟，网页另显示本步的编号参考照片，照片不是实时画面。

每次实测停稳后，相机线程关闭并重开设备，从本轮采集生成照片和观测；首次读取仅用于预热，随后读取的画面作为本轮照片。这是因为一次正常启动的首帧明显过曝，并不证明丢弃首帧能清除相机内部缓存。拍摄预算为 3 秒，拍不到有效目标则结束任务并保持停车。每张照片绑定本步的 MCU 会话和轮式起点，上传和启动前重新确认未取消、反馈有效且起点未变；照片不得跨动作复用。重新打开用于清除本进程及驱动队列，不能据此保证相机内部没有缓存或得知曝光时刻，须在现场改变标签位置后验证实际照片。

RK 启动时显式指定 `--dock-camera` 才启用只读画面。目标 ID、尺量边长（米）及相机高度、yaw/pitch/roll 安装角须分别使用 `--dock-tag-id`、`--dock-tag-size-m`、`--dock-camera-height-m` 和 `--dock-camera-yaw-deg`、`--dock-camera-pitch-deg`、`--dock-camera-roll-deg` 指定。只读预览不需要打开 `--dock-visual-verified`。在确认成像模式、标定和 50/30/20 cm 及左右偏移的静态测距、方向和完整入画通过之前，不使用该开关。开启它也不能代替现场确认和逐步动作验收。

对接须配套本候选 MCU：V12 单段 kind 3 倒车及 kind 4 转向，不兼容旧固件的动作能力；旧固件拒绝上传时不会发送 START。固定 1 RPM，每步倒车不超过 5 cm、转向不超过 5°；结束容差分别为 5 mm、1°。每个对接单步只使用 MCU 原有的 30 秒租约，不自动续租；普通导航仍按原规则续租。已接受的短步执行期间不依赖参考照片保持新鲜或标签持续可见，结束并确认停稳后重新拍照；如新照片无有效目标，任务结束且不自动恢复。人工停车、底盘故障或反馈失效仍触发原停车机制。普通 MOVE/TURN 和既有 5/3/3 RPM 保留；候选固件沿用实机 33V 上限和停车证明参数。MCU 到段不等于视觉对准或尺量精度通过。

首轮现场单步接口默认关闭。经过静态验证并在当次场地确认后，可在 RK 启动时额外指定 `--dock-single-step-test`，使用既有 PC 网关同源令牌向 `/api/dock/step` 提交 JSON：`{"kind":"move","value":-0.03}` 表示倒车 3 cm；`{"kind":"turn","value":0.0523598776}` 表示逆时针约 3°。倒车范围为 2～5 cm，转向绝对值大于 1° 且不超过 5°。单次完成并实测停稳后结束，不自动进入闭环；接口仍要求视觉有效、底盘停稳，并与普通导航互斥。当前网页没有为此接口提供单步按钮。

本轮只部署独立的只读相机预览，导航候选与固件候选均未部署或烧录，未执行实车动作。后方近场不受现有雷达保护。现场工作需重新核对实际设备、场地与停车状态，清空后方并人工看护；依次做静态图像检查、2～5 cm 倒车和左右小角度单步，再接视觉闭环。正对、左右偏移均需重复并尺量终点，另覆盖遮挡、断流、错误 ID 和人工停车。

2026-11-11 只读预览中，用户报告约 50、30、20 cm 时，视觉距离分别约 50.3、29.9、20.4 cm；用户报告的距离为大致值，不能据此计算精确误差或判定通过。20 cm 处用户报告一次横向移动约 5 cm，偏差读数从约 +1.0 cm 变为 −4.4 cm。随后标签移出画面右缘，识别状态显示丢失。这些观察均在独立预览、`verified=False` 下完成，安装角暂按零计算；图片来源与样本保存在项目工作区 `output/dock_static_20261111`。出现标签旋转 90° 时横向公式错误，已修复并用四个图案旋转方向合成回归；仍需相反偏移、精确尺量、缓冲延迟及现场动作验收。

2026-11-12 独立相机暂停试验中，读取间隔约 1.57 秒，但恢复首帧的手机时钟仍接近暂停前，强烈提示缓冲旧画面被重新计龄；手机屏幕停更等替代解释尚未完全排除。此前为连续读取设计的 0.5 秒锁存候选在一次真实冷启动中因首次读取耗时约 572 毫秒而锁定，未部署；用户随后明确选择停稳拍照短步方案。现场采样及误差限制见项目工作区 `output/dock_latency_20261112`。
